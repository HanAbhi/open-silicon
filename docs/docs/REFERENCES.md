# References and Further Reading

This project is an independent educational experiment exploring a small RTL-to-GDSII workflow using open-source tools. The following resources provide broader context on open-source silicon, ASIC design, and open hardware.

## Open-Source ASIC Design

1. **[Can We Do an Open Source Chip Design in 45 Minutes? — FOSDEM 2023](https://archive.fosdem.org/2023/schedule/event/open_source_chip_design/)**  
   A practical introduction to the open-source chip-design ecosystem and the process of taking a design through a chip-design flow.

2. **[Getting Started with Open Source Silicon — IEEE Solid-State Circuits Society](https://resourcecenter.sscs.ieee.org/education/webinars/sscsweb4104)**  
   An educational presentation by Matthew Venn introducing the open-source silicon landscape.

3. **[Basics to ASICs, the Open Source Way](https://sites.google.com/aucegypt.edu/basics2asics/schedule)**  
   Workshop resources covering open-source ASIC design, RTL-to-GDSII concepts, and OpenLane.

4. **[Open-Source ASIC Design — FPGA Ignite 2023](https://fpga-ignite.github.io/fpga_ignite_2023/openlane/KG_OpenLane-1.pdf)**  
   Presentation material introducing open-source ASIC design and the OpenLane flow.

## Related Open Hardware and FPGA Resources

5. **[How to Run Linux on RISC-V with Open Hardware and Open-Source FPGA Tools — FOSDEM 2020](https://github.com/pdp7/talks/blob/master/fosdem20.pdf)**  
   A related talk exploring open hardware, RISC-V, and open-source FPGA tooling.

6. **[CARP ASIC Class Slides](https://cal-poly-ramp.github.io/docs/asic-class/asic-class.html)**  
   Additional educational material on ASIC design concepts.

## How These Resources Relate to This Project

This repository focuses on a combinational 4-bit ALU implemented in Verilog and explored through Icarus Verilog, Yosys, OpenLane 2, the SkyWater SKY130 PDK, and KLayout.

These references provide background and learning material. They do not imply that this project reproduces the designs or results presented in the linked resources.

Please follow the relevant licensing and attribution requirements when reusing external material.
